# 产线工装板接口清单

**这份文件是给硬件工程师的。** 它回答一件事：**产线自动判定需要工装板提供什么。**

产线测试指南（`OPLC-MFG-TEST-001`）3.6 / 3.10 反复出现「PC external companion board」。那块板目前不存在，而 AI/AO 校准、DI 激励、高边与继电器的电压电流判定**全部指向它** —— 没有它，那几项落不了地。分工已定：**板归硬件做，软件按这份清单写驱动**（[DECISIONS.md 第 19 条](DECISIONS.md)）。

逐项差距在 [PRODUCTION-TEST-GAP.md](PRODUCTION-TEST-GAP.md)，本文不重复。引脚与端子事实以 [HARDWARE-FACTS.md](HARDWARE-FACTS.md) 为准，本文只引结论。

---

## 一、三条硬约束，设计前先看

### 1 · 控制通道是 RS232 端子，工装板不许碰

上位机和 DUT 之间唯一的控制通道是 **RS232 端子 C05 (TxD) / C06 (RxD) / C02 (GND)，115200 8N1**。产线指南自己写的也是「controls DUT via RS232」，一致。

⚠️ **端子是真 ±12 V**，工装板若要接必须走 RS232 收发器，**不能直连 TTL**。

⚠️ **RS232 端子的测试就是这条线自己**（`loop=self` 会话），所以这一项**不需要工装板参与**。

### 2 · 扩展口的 `PH13 / PH14` 就是控制通道那个 UART

扩展口（Junction Link J4-11 / J4-12）上的 `PH13 / PH14` **也是 UART4** —— 和 RS232 控制口是同一个外设，**一个 UART 只有一个句柄槽位，最后一次 `begin()` 赢**。

**后果**：工装板不能在扩展口上驱动 UART4，否则控制通道当场断掉，测试无法继续。扩展口的 SPI2 / SPI6 / I2C2 可以测，**UART4 那一对要么跳过，要么单独做一个「测完就断」的专项**。

### 3 · 模拟前端的档位已定，且焊上不可逆

| 通道 | 端子 | 档位 | 工装板要给什么 |
|---|---|---|---|
| **AIN1** | D12 | **电压档** | 可编程 **0–10 V** |
| **AIN2** | D13 | **电流档** | 可编程 **0–20 mA** |

**这不是可选的** —— 档位由锡桥决定（AIN1 桥 JP9 脚2-3 + JP5 脚1-2；AIN2 桥 JP8 脚1-2 + JP6 脚2-3），**出厂全开路，焊上不可逆**。所以工装板**不需要**每通道两种档都支持，一路电压源 + 一路电流源就够。

⚠️ **产线必须确认每块板都按这个档位焊了。** 没焊的话 MCU 引脚彻底悬空，读到的约 380 mV（抖动 200–650 LSB）是悬空脚，不是端子信号 —— 软件侧会当「悬空带」报出来，但那是**兜底不是判据**。

## 二、逐通道：工装板要提供什么

### DI —— 8 路，端子 D02–D09

| 项 | 要求 |
|---|---|
| 激励 | **每路独立可控的 24 V 通 / 断**，8 路互不影响 |
| 电平 | 判据阈值 **4.04 V，无回差**。产线要「逐通道阈值测试」（风险 R04），所以**激励电平最好可调**，不只是 24 V / 0 V 两态 |
| 负载 | DUT 侧 24 V 输入时吃 **2.16 mA**（12 V 时 1.08 mA），工装板的源要能带 8 路同时导通 |
| 回读 | **不需要。** DUT 自己把八路状态当位域报出来（`v=0x..`），上位机拿它和工装板设的激励比 |

⚠️ **DI 是输入。** 产线指南 3.6/3.10 那句「上位机控制 DI 通断，外部工装板检测 DI 输出」措辞矛盾 —— 见第五节。

### DO 高边输出 —— 8 路，端子 A03–A10

| 项 | 要求 |
|---|---|
| 负载 | **每路一个轻载**（产线要求「空载 / 轻载」两态）。器件每路限流 ≥3.8 A、导通电阻 160 mΩ，**但那是器件能力不是系统额定**（风险 R07），轻载具体多少等限值签署 |
| 测量 | **每路的电压和电流都要读回**。这是产线判据的唯一来源 —— DUT 侧**没有任何输出诊断回读**（VNQ5160K-E 有诊断脚，但没接到 MCU） |
| 采样率 | 要能跟上 PWM。软件 PWM 频率范围 **1–2000 Hz**，其中**上限是猜的** —— VNQ5160K-E 没有数据手册，实际上限要示波器实测（[PORTTOOL-FIRST-BENCH.md](../test/PORTTOOL-FIRST-BENCH.md) 的 M1）。**测 PWM 只需要平均电流，不需要逐沿捕获** |
| 保护 | ⚠️ **无全局限流**，整体保护只靠芯片过温关断（风险 R07）。工装板的负载和源要自己带保护，别指望 DUT 兜 |

### 继电器 —— 6 路，端子对 B01+B02 … B11+B12

| 项 | 要求 |
|---|---|
| 测量 | **每路触点串一个源 + 限流电阻，量电阻两端** —— 这是判「触点真的动了」的唯一办法 |
| 为什么必须工装板做 | **板上没有触点回读通道。** DUT 只能报「已驱动」，报不了「已吸合」 |
| 时序 | 吸合 ≤8 ms / 释放 ≤4 ms（器件值），系统级响应还要加固件周期，**未实测** |
| 触点规格 | 6 A / 30 VDC 或 6 A / 250 VAC（器件值，**不是系统额定**）。产线测试只需轻载判通断，**不要用额定值去做** |

### AI —— 2 路，端子 D12 / D13

| 项 | 要求 |
|---|---|
| 激励 | AIN1：可编程 **0–10 V**；AIN2：可编程 **0–20 mA**（档位见第一节第 3 条） |
| 精度 | 要比 DUT 指标高一档。DUT 标称 0.1 %，**但那个指标本身还没确认是硬的**（见第五节 Q2）—— 精度要求等它定 |
| 采点 | 产线要五点：**零 / 25 % / 50 % / 75 % / 满量程** |
| DUT 侧输入阻抗 | 电压档 90.6 kΩ；电流档总阻 498 Ω（其中 374R 是保护电阻，不参与换算） |
| 耐压 | ⚠️ **短时最大 13 V。** 工装板的源必须自己限幅，超了会伤前端 |
| 回读 | 不需要。DUT 报 `raw/mV`，换算到端子量由上位机做（换算系数在 [HARDWARE-FACTS.md](HARDWARE-FACTS.md)） |

### AO —— 2 路，端子 D14 / D15

| 项 | 要求 |
|---|---|
| 测量 | **每路的实际输出电流要读回。** 这是产线判据的唯一来源 —— **板上没有任何通道能读回 AO 的实际输出** |
| 负载 | 电流输出要求负载 **≤750 Ω**；若某板焊成电压输出则要求 **≥2 kΩ**。工装板要按实际档位配 |
| 期望值 | `Iout = Vin × 10 / 1024`，**只在跳线 JP3 / JP4 开路时成立**。闭合则变成 4–20 mA live-zero（DAC 设 0 时已有约 4.85 mA）。**这也是固件读不回来的焊接选择，产线要确认** |
| 采点 | 同 AI，五点 |
| 顺带 | DUT 有 `PI4 / PE3` 两个 XTR111 **开路 / 过载报警**脚（目前固件没用）。工装板做开路和过载两种工况的话，这两个标志可以当交叉验证 |

### 电源轨与功耗

| 项 | 要求 |
|---|---|
| 输入 | 24 V，**产线要程控**（限流可配 + 可记录）。工作范围 24 V ±20 %，下游 DCDC 最大耐 36 V |
| 要测的轨 | **3.3 V / 5 V / 5V_EXT**，判据「暂定值 ±5 %」。5V_EXT 经 0.5 A 可复位保险丝，输出 0.5 A |
| 功耗 | 两个数：**关掉全部功能的待机功耗**、**测试过程中的最大功耗** |
| 形态 | 产线指南写的是「上位机从测量模块的**寄存器**读值」—— 需要明确是什么总线、什么寄存器映射（见第三节） |

### DIN 导轨连接器 / 扩展口

| 项 | 要求 |
|---|---|
| 形态 | 产线指南写的是「**DUT 自测回环**，结果经 RS232 报出」—— 也就是**工装板只需要把信号短接成环**，判定在 DUT 侧 |
| 要环起来的 | 20 脚扩展口：5 V / GND、**SPI2**、**I²C2**、**SPI6**、JTAG、`DEBUG_TRIGGER`，信号电平 3.3 V |
| ⚠️ 不要环 | **UART4（`PH13/PH14`）** —— 见第一节第 2 条 |
| 隔离 | 扩展口无隔离、无浪涌、无 ESD 防护。工装板侧别引入外部干扰源 |

### 通信端口的对端（Golden endpoint）

这些**不一定要做进工装板**，也可以是独立设备，但产线每个工位都要有：

| 端口 | 端子 | 对端要什么 | 备注 |
|---|---|---|---|
| RS485 | C09 / C10 (A/B) | 一个 RS485 对端，波特率可配 | ⚠️ DUT 侧**无终端电阻、无偏置、无隔离**（风险 R06）。长线要外接终端 |
| CAN | C07 / C08 | CAN 对端，波特率可配，终端可切 | ⚠️ DUT 侧 **120 Ω 终端出厂断开**（JP7 未焊）。收发器是隔离型 `ISO1044`，**隔离侧靠 U7 供电，U7 不出电就驱动不了总线** |
| KNX | C03 / C04 | **KNX 电源（总线 20–32 V）+ Golden node / 分析仪** | 内部已集成 120 Ω 终端；2500 V 光耦隔离 |
| RS232 | C05 / C06 / C02 | **就是控制口自己**，不需要额外对端 | 见第一节第 1 条 |
| 以太网 | RJ45 | 10/100 M 交换机 + 一个固定的文件收发端点 | 产线要「传文件 + 报速率」 |
| USB | Type-C | USB **Host** 侧的固定端点 | ⚠️ DUT 是 **Device**，不支持 Host |
| SD | J6 | 标准卡组 | 1-bit SDIO，带插卡检测 |

## 三、工装板 ↔ 上位机：软件这边需要什么形态

这一节是**请硬件侧确认或提要求**的，不是已定的。

| 问题 | 软件侧的倾向 | 理由 |
|---|---|---|
| 什么总线 | **USB 虚拟串口**，或 RS485 / 以太网 | 上位机已经有一套串口层（`internal/serialx`，带 VID/PID 枚举），加一个串口设备成本最低。产线机器上**零安装**是硬约束（[DECISIONS.md 第 7 条](DECISIONS.md)） |
| 什么协议 | 文本行，`k=v`，一行一个回复 | 和 DUT 的 `pt.*` 协议同构，上位机能复用同一套解析和判据代码。产线指南说的「读寄存器」也可以，但要给出完整寄存器表 |
| 要能单独寻址 | 每个通道一个地址，**逐路可设 / 逐路可读** | 产线要「全通道覆盖」（DI8 / AI2 / AO2 / HS8 / Relay6 逐路记录） |
| 上电默认态 | ⚠️ **全部输出关断、全部激励断开** | 上电即给激励会在没夹好线的时候放电。DUT 侧的会话也是这个规矩（`pt.start relay` 先释放全部六路再驱动选中的） |
| 自身健康 | 有一条「工装板自检 / 版本」查询 | 产线要求 Golden 验证和治具寿命计数（风险 R10：探针磨损与接触电阻会造成**假失败**） |

## 四、不需要工装板的项

避免重复投入，这些明确不用：

| 项 | 为什么不用 |
|---|---|
| 板载温度（2× LM50） | 片内测量，DUT 直接报 mV / 0.1 °C |
| SDRAM / SD 压力自测 | DUT 自测，工装板不参与（SD 要标准卡组，那不是工装板） |
| RS232 端子 | 就是控制通道自己 |
| RTC | DUT 自读自写 |
| 指示灯 | 产线指南明确写人工目视判定 |
| SWD / 烧录 | 独立 JLINK，产线指南 2.4 已排在工站 1 / 6 |

## 五、还要硬件侧回答的两件事

### Q1 · DI 那句措辞

3.6 和 3.10 都写「上位机控制 DI 通断，**外部工装板检测 DI 输出**」。**DI 是输入**，能被「检测输出」的只有工装板自己给的激励。

**软件侧的理解**：工装板给激励，DUT 读回并上报，上位机拿两者比对。**如果原意不是这个，请说明。**

### Q2 · AI / AO 的 0.1 % 是硬指标吗

规格书 5.2 自己的备注：

> Accuracy 0.1 % — **Requires 24 V supply and full-temperature calibration**；mainstream AO typically specifies 0.3 % / 0.6 % grade target.

**这条决定两件事**：工装板的测量精度要求，以及**要不要做逐板校准**。松到 0.3 % 的话，逐板校准很可能整件事不需要，工装板的精度要求也跟着降一档。

背景与三条备选路在 [PRODUCTION-TEST-GAP.md](PRODUCTION-TEST-GAP.md) 的 Q2。
