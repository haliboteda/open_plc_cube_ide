# 🍍 示波器量 DO 的 PWM 上限 —— 步骤表

**要回答的问题**：DO 前面那颗 **VNQ5160K-E 智能高边开关**，PWM 到多少赫兹就出不来了？极窄和极宽的占空比还出不出得来？

**为什么必须量**：它不是裸 MOSFET，内部有电荷泵和保护逻辑，**没有数据手册可查**（[../design/DECISIONS.md 第 10 条](../design/DECISIONS.md)）。固件里 `PORT_DOUT_FREQ_MAX_HZ = 2000` 是留宽让你去量的数字，**不是器件的真实能力**。

---

## 准备

| | |
|---|---|
| **探头** | 接 **A03**（Digital Out 1），地夹接 **A01** 或 **A02**（GND） |
| **档位** | ⚠️ **必须 1:10。** 24 V 在 1:1 档下会削顶，看到的波形是假的 |
| **示波器** | 时基先设到能看见 2–3 个周期；触发设上升沿，电平约 12 V |
| **面板** | `dout` 卡片，左边树上**只勾第 1 路** |
| **负载** | 先空载量。空载过了再按下面第三组挂负载 |

---

## 第一组：扫频（找频率上限）

`duty` 固定 **50**，改 `freq`，每改一次点「重新启动」。

| # | freq | 幅度到 24 V 吗 | 还是方波吗 | 上升时间 | 实测占空比 |
|---|---|---|---|---|---|
| 1 | 50 | | | | |
| 2 | 100 | | | | |
| 3 | 200 | | | | |
| 4 | 500 | | | | |
| 5 | 1000 | | | | |
| 6 | 1500 | | | | |
| 7 | 2000 | | | | |

**「塌了」长这样**（任一条成立就记下来）：

- 高电平**到不了 24 V**（比如只到 18 V）→ 电荷泵跟不上开关速度
- 波形从方波变成**三角波或锯齿**
- **上升沿明显变缓**，占到周期的相当一部分
- 屏幕上量到的占空比**和 50% 对不上**

⚠️ **如果 2000 Hz 还好好的**，说明器件还能往上，但软件 PWM 到顶了（中断率 = freq × 100，2000 Hz 时已经 200 kHz）。**那种情况下才值得做硬件 PWM。** 请在表格末尾写一句「2000 还好」。

---

## 第二组：极端占空比（这一组比扫频更要紧）

`freq` 固定 **1000**，改 `duty`。**智能开关有最小导通时间，极窄脉冲很可能压根出不来** —— 这正是 [DECISIONS.md 第 10 条](../design/DECISIONS.md)里明写「未验证」的那条。

| # | duty | 脉冲还在吗 | 实测占空比 | 幅度 |
|---|---|---|---|---|
| 1 | 2 | | | |
| 2 | 5 | | | |
| 3 | 10 | | | |
| 4 | 50 | | | |
| 5 | 90 | | | |
| 6 | 95 | | | |
| 7 | 98 | | | |

**要找的是两个边界**：**最小能出来的 duty** 和 **最大能出来的 duty**。比如「duty=5 还有脉冲，duty=2 就没有了」。

---

## 第三组：带负载（如果手边有负载）

空载和带载对这种智能开关差别可能很大 —— 电荷泵要驱动的容性负载不一样。

`freq=1000`、`duty=50`，在 **A03 和 GND 之间**挂一个负载（比如 24 V 的指示灯，或者几百欧的功率电阻），重复第一组里塌掉的那几档。

| freq | 空载 | 带载 |
|---|---|---|
| （填第一组里出问题的那几档） | | |

**没有合适负载就跳过这一组**，在结果里写「未测」就行 —— 比编一个数强。

## 量完之后

把三张表填好的内容给我，我做三件事：

1. 补进 [../design/HARDWARE-FACTS.md](../design/HARDWARE-FACTS.md)，**这是这颗器件唯一的数据来源**
2. 把固件的 `PORT_DOUT_FREQ_MAX_HZ` 从 2000 改成实测上限，`duty` 的可用范围同理
3. 回答「要不要做硬件 PWM」：**2000 Hz 还好 → 值得做；500 Hz 就塌 → 软件 PWM 绰绰有余，硬件 PWM 白做**

## 面板上具体怎么操作

1. 左边树里点开 `dout`，**只勾第 1 路**（勾多了会有别的通道一起在跳，示波器上不好认）
2. 中间卡片：`duty` 那一格（标着 `A03`）填数
3. `freq` 那一格填数
4. 点「**重新启动**」
5. 帧里回报的 `ch1=` 是当前占空比，`tick=` 是中断率 —— **`tick` 应该等于 freq × 100**，不等就是没生效

⚠️ 面板独占 COM12。**我这边要用板子的话会先跟你说，你量的时候我不碰。**
