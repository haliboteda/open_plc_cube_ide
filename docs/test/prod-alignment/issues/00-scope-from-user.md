# 00 · 没有陪测板和外接仪器时，产测的边界在哪

Type: grilling
Status: resolved（2026-09-13）

## Question

文档工站 6 / 10 里有一大批判定写着「测试软件读取 PC 外接电压电流测试模块」「通过 PC 外接陪测板检测」「控制 PC 外接信号发生仪」。**这些设备一台都没有。** 那这些项怎么办？

## 答案（用户 2026-09-13 定）

**「没有陪测板，一切以板子整体测试为方案」**、**「目前没有外部仪器，只能是 log 上来，上位机读取来看，并且，硬件自己跳线自己看示波器和万用表」**。

落成 `DECISIONS.md` 第 39 条。三分法：

| 类 | 怎么办 |
|---|---|
| 板子自己有通路测得到 | 做成会话 / `pt.run`，数据从控制口上来，上位机判 |
| 板子没有通路 | **不写代码**，列成人工项，硬件工程师跳线 + 万用表 / 示波器 |
| 要外接可编程仪器 | 不做。等真有实物和型号再谈 |

## ⚠️ 核实出来的硬件事实：板子测不了任何电压和电流

查 `Hardware/*_overview.txt` 与 `STM32H743IIK6_GPIO_ASSIGNMENT_*.xlsx`：

- **24V / 3V3 / 5V0 / 5V_EXT 没有任何分压采样** 进 MCU
- **VNQ5160K-E 的电流 sense 没有回到 MCU** —— Lower Deck 只有 `HIGHSIDE_FET1~8` 驱动信号
- 板上的模拟通道只有：`PA0` 短路保护温度、`PA3` Fets 温度、对外的 `AIN1(PC3)` / `AIN2(PA6)` / `AOUT1(PA4)` / `AOUT2(PA5)`，外加 `PB1`/`PF9` 两个**预留未接**的高速 ADC 通道

**所以文档里这五项无论软件怎么写都拿不到数**，它们是人工项，不是没写完的功能：待机功耗、最高功耗、3.3V/5V/5V_EXT 电压、高边输出电压电流、继电器触点电压电流。

## 顺带解开的一条

**AOUT → AIN 跳线可以自证一条模拟环路**（用户说的「硬件自己跳线」正是这个）。⚠️ AOUT 是**电流**输出（XTR111，文档风险 R05 也确认「产测仅按电流输出」），AIN 是电压输入，**中间要一个已知阻值的电阻**。这条能验 DAC→ADC 整条链路的线性度，但**验不了绝对精度** —— 两头共用同一个 VREFBUF，基准误差会同向抵消。
