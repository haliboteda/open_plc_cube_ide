# 04 · 逐项三分：板子自证 / 人工 / 不做

Type: task
Status: open

## Question

在「没有陪测板、没有外接仪器」（`DECISIONS.md` 39）的前提下，把文档工站 6 和工站 10 的**每一个测试项**分成三类，并写清楚自证的那一类判据取自哪个帧字段。

## 三类的判准

| 类 | 判准 |
|---|---|
| **板子自证** | 激励和读回都在板内，或靠一根跳线就能闭合 |
| **人工** | 板子没有通路，硬件工程师跳线 + 万用表 / 示波器 |
| **不做** | 要外接可编程仪器（`DECISIONS.md` 39） |

## 已经能填的几行（其余待逐条过）

| 文档测试项 | 分类 | 依据 |
|---|---|---|
| SDRAM 压力 | 自证 | `pt.run sdram.probe/sweep/retention` |
| SD 读写压力 | 自证 | `pt.run sd.integrity/stress/speed` |
| 温度传感器 | 自证 | `temp` 会话读 PA0/PA3 |

| 高边输出「通断」 | **自证** | 同上，靠 DI 读回证明输出真的动了 |
| 高边输出「电压电流」 | **人工** | 板子无采样 |
| 继电器「通断」 | 自证（触点接到 DI 上） | 待确认接法 |
| 继电器「触点电压电流」 | 人工 | 板子无采样 |
