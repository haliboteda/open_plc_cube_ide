# 07 · 配置项落进面板：分类、说明、用法、互斥

Type: prototype
Status: open
Blocked by: 01

## Question

按 [DECISIONS.md 第 41 条](../../../design/DECISIONS.md)，把 [PROD-CONFIG-ITEMS.md](../../PROD-CONFIG-ITEMS.md) 的九个分类和十四条互斥**落到面板上**。产线工程师不改代码就能配出一个工站的完整测试序列。

## 要做的四件

1. **左边列表按九个分类分段** —— 连接 / 范围 / 方式 / 端口参数 / 判据 / 安全 / 记录 / 人工 / 校准。⚠️ **端口本身仍按板子分组**（`Bridge / Upper / Lower / 整板`），那条 2026-09-13 已定，不要重开。
2. **每一项旁边写「是什么、怎么填」** —— 出处是固件文件头的注释和 `pt.caps`，不在面板里另编一份。
3. **互斥当场说出来**，不是试了才报错：
   - 勾中组合超带宽 → 「开始」置灰 + 说清超了多少、怎么改（**已有**）
   - 勾了 `rs485` 但没有对端 → 提示它半双工听不到自己
   - 勾了 `dout` 或 `din` 其中一个 → 提示回环矩阵要两个都勾 + 一根八芯线
   - `relay` 周期填小于 1000 → 当场拦，不等固件拒绝
   - `dout` 的 `freq` 填超 2000 → 当场拦
   - 勾了 `ain` → 直接说「引脚悬空，等焊 JP5/JP6/JP8/JP9」
   - `aout` 的期望值旁边说明取决于 JP3/JP4 焊没焊
4. **`kind=run` 的一次性目标和「持续」分开摆** —— 它们是阻塞的，混不进一轮。

## 边界

⚠️ **限值仍然不可编辑**（第 30 / 34 条）。本票管「跑什么、怎么跑」，不管「多少算过」。

⚠️ **H5 断言按 `data-*` 属性找元素，不要按屏幕上的文字** —— 面板一改措辞，按文字找的断言就全瞎。
