# 产测配置项总表

**这份回答一件事：产线工程师坐在上位机前面，能配的每一样东西是什么、怎么填、和谁打架。**

依据 [DECISIONS.md 第 41 条](../design/DECISIONS.md)。⚠️ **限值不在这里** —— 判据仍然只能靠换一份方案文件调（第 30 / 34 条），本表管的是「跑什么、怎么跑」，不是「多少算过」。

## A · 连接

| 配置项 | 说明 | 用法 |
|---|---|---|
| **控制串口** | 板子的 RS232 控制口，端子 **C05 / C06 / C02**。**所有命令和所有数据都走这一根线** | 面板左边列出系统里的串口，像是 RS232 适配器的会标出来。上次用过的会记住，但**不自动连** —— 打开串口是副作用 |
| **波特率** | **固定 115200 8N1**，不可改 | 不是配置项，写在这里是因为分类 C 的带宽守卫按它算 |

## B · 测试范围

| 配置项 | 说明 | 用法 |
|---|---|---|
| **端口复选** | 勾中的端口这一轮一起跑。**只有会话类（`kind=session`）能勾** | 左边列表每行前面一个勾。一次能勾多个 |
| **通道复选** | 多通道端口（DO 八路、DI 八路、继电器六路、AI/AO 各两路）选测哪几路 | 端口卡片上每路一个勾 |
| **一次性目标**（`pt.run`） | 跑完就回来的单项：SDRAM 三项、SD 四项、以太网链路、RTC 读、指示灯闪 | 卡片上单独一行一个按钮，不进复选 |

⚠️ **`kind=run` 的目标是阻塞的** —— 跑的时候独占 CPU，跑完才还回来。所以它们不能和「持续」混在一轮里。

## C · 测试方式

| 配置项 | 说明 | 用法 |
|---|---|---|
| **单次** | 跑一轮，跑完自动停，**给一个结论** | 验收用 |
| **持续** | 一直跑到时长用完，**不自动给结论** | 老化、调波形、量电压用 |
| **时长** | 1 / 2 / 3 / 4 小时 / 一直 | 只在「持续」下出现 —— 单次跑几秒，问它跑多久没有意义 |

## D · 端口参数

**每个端口报给面板的参数，来自固件的 `pt.caps`，不是面板写死的。** 加一个端口只要改固件，面板自己就长出来。

| 端口 | 参数 | 说明 | 用法 |
|---|---|---|---|
| `dout` | `ch` `mode` `duty` `freq` `period` | 八路 24 V 高边输出，**每路独立占空比和频率** | `duty=0` 是关、`100` 是开；`mode=blink` 配合 DI 回环用 |
| `din` | `ch` `mode` `period` | 八路数字输入 | `mode=quad` 是编码器模式 |
| `relay` | `ch` `period` | 六路继电器 | ⚠️ **周期下限 1000 ms**，不是别处的 50 |
| `ain` | `ch` `period` | 两路模拟输入 | ⚠️ **现在测不了**，引脚悬空，等焊 JP5/JP6/JP8/JP9 |
| `aout` | `ch` `mv` `period` | 两路模拟输出，**电流输出** | `mv=1:500` 期望 4.883 mA；⚠️ 焊了 JP3/JP4 就变 4–20 mA live-zero，期望值不成立 |
| `temp` | `ch` `period` | 板载两路温度（PA0 短路保护 / PA3 Fets） | 单位是十分之一摄氏度 |
| `can` | `baud` `mode` `period` | `normal` / `listen` / `loopback` / `extloop` | `extloop` 是产线要的：过收发器和隔离器，**不需要第二个节点** |
| `rs485` | `baud` `period` | A/B 对上发号收号 | ⚠️ **必须有对端**，见互斥 6 |
| `knx` | `mode` `ga` `src` `val` `crc` `period` | `mode=frames` 发真报文 | `ga=none` 停发；默认发到 **31/7/255** |
| `rs232` | `period` | **它就是控制口本身** | 见互斥 1 |
| `eth` | `mode` `period` | TCP server：`echo` / `sink` / `source` | 板子 IP 是 DHCP 来的，唯一可信出处是帧里的 `ip=` |
| `usb` | `mode` `period` | CDC，板子是 **Device** | PC 才是主机 |
| `sd` | `period` | 会话只盯「卡插没插」；读写在 `pt.run` 里 | 判据是 `fs ne none` |

## E · 判据（只读）

**判据来自方案文件（`$TOOL/TestCase/plans/*.json`），面板上只显示不编辑。**

| 配置项 | 说明 | 用法 |
|---|---|---|
| **方案文件** | 一个工站一份。步骤、参数、判据都在里面 | 换工站就换一份文件 |
| **判据展示** | 每一步「什么算对」照实显示 | 只读。要改限值改文件 |
| **参数留痕** | 面板上改了参数会写回方案文件 | 改了限值不会 —— 限值不可编辑 |

## F · 安全联锁

| 配置项 | 说明 | 用法 |
|---|---|---|
| **看门狗 `pt.hold`** | 上位机每 2000 ms 说一次「我还在，再给我 6000 ms」。到期板子 `stop_all()` + **自己点故障灯** | **只有「持续」武装**。续期在服务端不在页面 —— 标签关了、笔记本睡了，24 V 不能还开着 |
| **故障灯 `pt.led`** | 判出故障时上位机点灯 | 灯**只表达「有故障」**，不表达是哪个端口（PE2 只一盏、无回读） |
| **带宽守卫** | 勾选时算「端口数 × 每帧字节 ÷ 周期」，超 115200 的 80 % 就拦住 | 见互斥 2 |
| **一个错全停** | 任一端口判出故障 → 停整轮 + 提示 + 点灯 | 不可关 |

## G · 记录

| 配置项 | 说明 | 用法 |
|---|---|---|
| **滚动日志** | 一轮持续测试开一个文件 `runlogs/run-<时间戳>.log` | 滤掉 `OK echo`（三行里的两行）。五个端口 × 200 ms 跑四小时约 29 MB |
| **测试报告** | 逐项原始值 + 结论 | 失败数据不覆盖 |

## H · 人工项

**这几项板子没有通路，只能人看。** 详见 [prod-alignment/逐项三分](prod-alignment/issues/04-board-selfproof-matrix.md)。

| 配置项 | 说明 | 用法 |
|---|---|---|
| **指示灯确认** | PE2 无回读，只能人看闪没闪 | 弹框，人选通过/失败 |
| **万用表读数框** | AOUT 电流、供电电压这类 | 人读了填进去，进报告。⚠️ 输入框**刻意放在每帧重建的区域之外**，否则打字打一半会被抹掉 |
| **安规判定** | 工站 9 | 弹框人选 |

## I · 校准

**系数在上位机算，板子只报原始读数**（第 22 / 38 条）。

| 配置项 | 说明 | 用法 |
|---|---|---|
| **采点** | 零点 / 25 % / 50 % / 75 % / 满量程 | 点数和期望值可配 |
| **拟合形状** | 先做一次线性（增益 + 偏置） | ⚠️ **形状要等真实数据**才定得了 |
| **系数落盘** | 先进测试报告，**板子不存** | 「存哪」仍挂在 `ISS-C1` |

# 互斥与依赖：十四条

**这些要在界面上当场说出来，不是试了才报错。**

| # | 关系 | 表现 | 出处 |
|---|---|---|---|
| 1 | **`rs232` 会话吃控制口带宽** | 它是 `loop=self`，测试流量和所有端口的日志是同一根线；每帧走三趟（90+16+20 字节），别的端口只算 90 | `$BOOT/TestCase/porttool/porttool_rs232.c:117`、`$TOOL/internal/ptpanel/web/index.html:2612` |
| 2 | **总带宽上限** | 勾中端口合计超 11520 B/s 的 80 % 就不让开始。**线一堵 `printf` 阻塞，所有端口采样周期一起失准且不报错** | `index.html:2665` |
| 3 | **`pt.echo` 对 `loop=link` 端口被拒** | `can` / `rs485` 的计数器必须走被测链路。在控制口上答它会让计数器在链路已死时照涨 | `porttool.c:423`、`DECISIONS.md` 9 |
| 4 | **`ain` / `aout` / `temp` 都要 VREFBUF** | 起不来就**拒绝启动**，不是给个坏数 | `porttool_ain.c:89`、`porttool_aout.c:136`、`porttool_temp.c:82` |
| 5 | **`relay` 周期下限 1000 ms** | 其余端口是 50。填小了固件拒绝 | `porttool_relay.c:57` |
| 6 | **`rs485` 必须有对端** | 半双工且是一条网：`PD4` 同时驱动 /RE 和 DE，**发送时板子听不到自己**。没有对端计数器永远闭合不了 —— 那是接线不对，不是会话有问题 | `porttool_rs485.c` 文件头 |
| 7 | **DO→DI 回环要一根八芯线** | `dout mode=blink` + `din` 两个必须一起配，判据是矩阵对角。DO 出 24 V、DI 耐 24 V，一根线覆盖十六个通道 | `porttool_dout.c` 文件头 |
| 8 | **AO→AI 跳线要串电阻** | AOUT 是**电流**输出，AIN 是电压输入。⚠️ 两头共用同一个 VREFBUF，**能验线性，验不了绝对精度** | [prod-alignment/边界](prod-alignment/issues/00-scope-from-user.md) |
| 9 | **`dout` 的 `freq` 封顶 2000 Hz** | 软件 PWM 跑在 TIM7 上，中断率 = `freq × 100`，2000 Hz 已经是 200 kHz 中断 | `PORTTOOL-FLOW.md:643` |
| 10 | **改了参数，方案判据当场失效** | 按钮改口成「按我改的参数跑（不出结论）」，并说清差在哪，另给一键「恢复方案参数」 | `index.html` 的 `offPlan()` |
| 11 | **「持续」才武装看门狗** | 单次不武装 —— 跑几秒钟，武装它只会误停 | `DECISIONS.md` 37 |
| 12 | **`kind=run` 目标是阻塞的** | 跑的时候独占 CPU，不能和「持续」的会话混在一轮里 | `porttool_run.c`、`PORTTOOL-FLOW.md:64` |
| 13 | **`ain` 现在整条测不了** | 那两个引脚彻底悬空，等硬件焊 JP5/JP6/JP8/JP9 | `AIN-JUMPER-REQUEST.md` |
| 14 | **`aout` 的期望值取决于 JP3/JP4 焊没焊** | 没焊：`mv=1:500` → 4.883 mA。焊了就变 4–20 mA live-zero，那两个期望值不成立 | `HARDWARE-FACTS.md` |

⚠️ **以下两条随交权入口退出而消失**（[DECISIONS.md 第 40 条](../design/DECISIONS.md)），列在这里是为了说明它们为什么不在上表里：`pt.handover pwm` 和 `dout` 抢 PA9；交权一次只能进一个且不返回。
